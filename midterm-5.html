Units and model: Y = A × K^0.3 × N^0.7. ALP = Y/N = A(K/N)^0.3. Y is total real output during a period; in the one-good examples, loaves per day. N is total labor hours in that day. K is real capital measured in consistent capacity units; A is an efficiency index. ALP differs from total factor productivity A, marginal productivity and output per person.

Graph examples: Reset to A = 1, K = N = 100 before each separate experiment. The productivity graph has K/N horizontally and ALP vertically. All curves, points, guides and labels use A(K/N)^0.3. Capital 100 → 120 with N = 100 moves along the unchanged A = 1 curve. A = 1 → 1.1 at K = N = 100 shifts the curve upward. Numbers are generated illustrations, not course estimates; displayed values are rounded.

Growth arithmetic: For ordinary percentage changes, gY ≈ gA + 0.3gK + 0.7gN, and g(Y/N) ≈ gA + 0.3g(K/N). The professor writes growth accounting using an equals sign; this relation is exact for log changes and approximate for the ordinary percentage changes used here. Exact level growth uses multiplicative growth factors. Contributions are percentage points, not automatically shares of observed growth.

Interpretation: Measured A is a residual and can reflect unmeasured input quality, utilization or measurement error as well as useful methods. The class treats A as exogenous when using the model; measuring a residual from data does not change that modeling choice. Capital deepening remains useful but faces diminishing returns in the course long-run argument. It is not a claim that all capital investment is ineffective.

Task-time example: SRC-012 slide 15’s X-ray illustration is a separate sequential-process example, not an output from the Cobb–Douglas graph. It holds scanning time and other capacity fixed; no overlapping tasks or parallel processing are assumed.
